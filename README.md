# pavel.bd

Personal digital hub / link-in-bio website for A S M Pavel Sarwar.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- No database required

## Local preview
Open `index.html` in a browser.

## cPanel deployment
Upload these files to the domain's `public_html` folder:
- index.html
- style.css
- script.js

## Editing links
Update the `sections` array in `script.js`.

## Status
Initial preview version. Replace placeholder `#` URLs with final organization/community links before production launch.
